Before you share it

  • Send the PNG as a file. Apps that recompress photos (WhatsApp, Instagram, Facebook, X, most chat apps when sent as a "photo") convert to JPEG or resize, and that destroys the hidden message. Email attachments, cloud drives, or "send as document" keep it.
  • Never convert it to JPEG, crop, resize, or edit it. Any change to the pixels breaks the message.
  • Hidden is not invisible to experts. This uses the least significant bit of each colour value, which forensic tools can detect. Use a password: then even if someone finds the data, they can't read it.
  • Some privacy-focused browsers (Brave, Safari private mode) add noise to images read by pages. The tool checks its own output and will tell you if your browser did this.
